LDJ CARD MAKER — OFFLINE PROTOTYPE v1.0
=======================================

START
1. Extract this ZIP if necessary.
2. Double-click LDJ_Card_Maker.html to open it in Chrome, Edge, Firefox, or Safari.
3. Choose "Council of Juliens", "Mother's Veto", or a blank card.
4. Edit the name, mana cost, card type, rules, flavor text, frame color and rarity.
5. Upload your own image, then adjust the zoom and horizontal/vertical position.
6. Download PNG to create a flattened finished card.

SAVING AND SHARING
- Click "Save editable card" to download a JSON project containing the card fields
  and uploaded artwork. This file can be opened later with "Open saved card".
- To share the maker, send just the single HTML file: all four LDJ badges and the two
  sample illustrations are included in it. No other files are needed.
- No server or login is required. Your images stay locally in your browser.
- The maker itself does not permanently autosave your edits. Download a JSON project
  before closing the tab if you want to return to a card later.

OUTPUT AND PRINTING
- Card physical dimensions: 63 x 88 mm, rounded corners approximately R 2.5 mm.
- PNG export: 1488 x 2079 pixels (approximately 600 DPI at 63 x 88 mm).
- PNG files may not carry 600 DPI metadata. When printing, set physical dimensions
  to 63 x 88 mm (or use the Print / PDF option with margins disabled).
- Frame dimensions and interior elements are based on LDJ card reference images and
  are approximations, not official licensed printing templates.

LIMITATIONS IN THIS FIRST VERSION
- Rules text supports line breaks and automatic font sizing, but does not provide
  full MTG-style rich-text symbols in the text box.
- Uploaded images are flattened into a high-resolution image upon PNG export.
- Rarity assets are selectable. For an additional logo, choose Custom Badge and
  upload your own transparent PNG.
- Does not provide accounts, online galleries, cloud synchronization or decks.
- This is an unofficial fan-made card editor, not an official MTG product.
